Muscle Trainer - static site (no build step)

Deploy on Vercel:
 Option A (drag and drop / CLI)
   1. Install the CLI once:  npm i -g vercel
   2. In this folder run:    vercel --prod
   3. Accept the defaults (Framework: Other, no build command, output dir: .)

 Option B (GitHub)
   1. Push this folder to a GitHub repo.
   2. On vercel.com choose Add New > Project > import the repo.
   3. Framework Preset: Other. Leave build and output settings empty. Deploy.

Everything (images included) is inside index.html, so there is nothing else to upload.
